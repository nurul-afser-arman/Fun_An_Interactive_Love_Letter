# Fun (An Interactive Love Letter)

> ✨ A cinematic, interactive love letter disguised as a web page.

Watch a rose grow from a single stem, bloom petal by petal in full 3D, and reveal a heartfelt message — all powered by pure front-end magic.

**No frameworks. No libraries. No build tools. Just code and love. ❤️**

---

## 🎬 Experience

| Step | What Happens |
|------|--------------|
| 🔒 **Loading Screen** | A frosted glassmorphic card displays a progress bar with poetic status messages |
| 🌱 **Stem Grows** | The stem rises organically while leaves and thorns unfurl |
| 🌹 **Rose Blooms** | 7 layers of petals open in a staggered 3D animation with a heartbeat pulse |
| 🌸 **Petals Fall** | Delicate petals drift and sway naturally across the viewport |
| 💕 **Hearts Float** | SVG hearts gently rise from the bottom of the screen |
| 💌 **Love Letter** | A glassmorphic card reveals a heartfelt message character-by-character |
| 🎵 **Ambient Music** | A built-in Web Audio synthesizer creates a soft ambient chord progression |

---

## 🖼️ Features

### 🌹 Full 3D CSS Rose
- 49 individually animated petals
- 7 layers of petals
- 3D transforms and perspective
- Randomized movement and jitter
- Staggered blooming animation
- Heartbeat-style pulse effect

### 🧊 Glassmorphism UI
- Frosted glass cards
- `backdrop-filter` blur effects
- Translucent rose-tinted backgrounds
- Inner light highlights
- Warm glowing effects

### ⌨️ Typewriter Love Letter
- Character-by-character typing animation
- Blinking cursor
- Adjustable typing speed
- Click to skip the animation

### 🎵 Generative Audio
- Built entirely with the Web Audio API
- Soft chord progression
- Arpeggiated notes
- Delay and feedback effects
- Built-in mute/unmute control
